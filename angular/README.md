# Frontend Angular - Medicamentos

Tela web que consome a API do backend (`http://localhost:8080/medicamentos`): lista, cadastra (POST) e edita (PUT) medicamentos, mostrando os erros de validação.

```bash
npm install
npx ng serve
```
Abre em `http://localhost:4200` (origem liberada no CORS do backend). O backend precisa estar rodando.

Testes: `npx ng test --watch=false`
